## 실제 코드 점검에서 확인된 문제
1. **사진 파일 읽기 경합:** 동일 대상에 사진 A, B를 연속 선택했을 때 먼저 선택한 A의 `FileReader.onload`가 늦게 완료되면 B를 덮어쓸 수 있음. G3-71의 `draftEpoch`는 초기화·삭제에만 증가했기 때문에 연속 파일 선택과 사진 복원을 보호하지 못했음.
2. **사진 원본 복원 경합:** 기존 업로드가 진행 중 원본 사진 복원을 눌러도 이전 `onload`가 뒤늦게 나타나 복원 상태를 다시 덮어쓸 수 있음. 잘못된 파일을 후속 선택한 경우에도 이전 읽기가 나중에 적용될 가능성이 있었음.
3. **모바일 편집 접근성:** 제품 헤더의 순서·삭제·접기 버튼과 개별 사진 복원 버튼은 36px였고, 입력 폰트는 15px여서 터치·일부 iPhone Safari 자동 확대 UX에 불리함. 모바일에서 긴 좌측 편집 영역 아래에 있는 실제 고객 미리보기로 바로 이동할 단축 경로가 없음.
4. **키보드 검색:** 관리용 검색 필드의 Escape 초기화 동작이 명시되지 않음.

## 변경 사항
