## G3-71 구현
1. **최근 삭제 취소(1단계):** 삭제한 상품의 ID·사진·가격·설명·가상 예약 가능 여부·분류·기존 위치·접기 상태를 해당 탭 RAM에 보관. 최근 삭제 건만 취소 가능. 다른 삭제가 일어나면 이전 삭제는 실행 취소 대상에서 제외. 초기화/새로고침 시 실행 취소 정보 삭제.
2. **사진 복원:** 각 상품 사진 아래에 '기본 상품 사진으로' 동작을 추가. 기본 사진이면 버튼 비활성화, 새로운 사진을 선택하면 변경 표시와 복원 버튼 활성화. 기존 JPG/PNG/WebP 3MB 제한 유지. 파일 읽기가 완료되기 전에 삭제/초기화가 일어나면 오래된 업로드 결과 적용 방지.
3. **상품 검색:** 상품명·영문명·설명·색상에서 대소문자 구별 없는 브라우저 탭 내 검색. 관리 목록에서만 필터링하며 고객 iframe의 진열/가상 예약 목록은 **절대 필터링하지 않음**. 표시된 결과 수·전체 상품 수·검색 결과 없음 표시, 지우기 버튼. 30개 상한과 G3-70 접기/정렬/섹션 이동 유지. 상품 추가/최근 삭제 취소 시 검색어를 초기화하여 편집 대상 노출 보장.
