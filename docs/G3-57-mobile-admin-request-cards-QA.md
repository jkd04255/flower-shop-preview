# G3-57 · 모바일 관리자 예약 카드 정보 위계 개선

## 목적
G3-55 상태 필터 및 G3-56 예약번호 검색·정렬 개선에 이어, 관리자 **예약 목록 카드**에서도 예약번호·상태·상품명·픽업 정보가 한눈에 구별되도록 시각적 위계를 정돈합니다. 새 기능이나 안내 문구는 추가하지 않습니다.

## 변경
- 600px 이하 모바일에서 카드의 여백과 행 간격을 조정합니다.
- 예약번호와 상태 배지는 첫 줄에 두고 줄바꿈 시에도 충돌하지 않도록 합니다.
- 꽃다발 이름을 18px로 통일하고 날짜·시간·가상 이름·가상 입금 상태로 이루어진 기존 상세 정보를 얇은 구분선 아래에 배치합니다.
- 선택한 카드에 연한 녹색 배경과 안쪽 3px 선을 적용해 현재 관리자 상세 보기의 선택 대상임을 더 명확하게 합니다.
- 카드 전체 클릭, 키보드 포커스, `aria-current`, 모든 기존 텍스트와 합성 예약 자료를 유지합니다.
- 601px 이상 데스크톱 스타일, 사진 소스, 모바일 꽃 사진 4:3, **'오늘의 꽃 만나기 ↗'**, 예약·조회·관리자·캘린더 동작 불변.

## 신규 테스트
`tests/g3-57-mobile-admin-request-cards-qa.cjs`
- Chromium/Linux WebKit: 320·390·600·768·1280px.
- 카드 배치 및 4건 합성 요청의 날짜·시간·상태 내용 유지, 작은 화면의 가로 넘침 없음, 데스크톱 기존 카드 스타일 유지.
- 카드 선택 및 상세 내용 동기화, 선택 표시·포커스 복구, 필터·전체 보기, localStorage·합성 데이터 불변 확인.
- 390px axe-core WCAG 2.1 AA 검사 및 스크린샷 증거.
