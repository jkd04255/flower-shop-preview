# 오후의 정원 G3-36 · 가장 늦은 픽업 시간·관리자 가상 예약번호 검색

## 변경 범위
- 기준: G3-35 `main` (f4142d2ecc9b6853587928a89251a6fe27324cac). 기존 디자인·사진·꽃다발·가격·고정 문구 `오늘의 꽃 만나기 ↗`·상품 카드 `상품 상세 보기 ↗` 및 G3-24~35 예약·관리자 UX 유지.
- 고객 예약에서 `가장 늦은 픽업 시간 선택 ↗` 버튼을 기존 날짜/가장 빠른 시간 버튼과 나란히 추가. 날짜를 선택하고 기존 `pickupSlots()`의 선택 가능한 슬롯이 있을 때만 활성화합니다. 사용자가 누르면 현재 날짜의 **마지막 유효 슬롯만** 선택하며 실제 예약·결제·시연 기록을 생성하지 않습니다. 날짜를 바꾸거나 삭제하면 시간과 빠른/늦은 안내를 지웁니다. 직접 시간 선택 시 해당 안내를 지웁니다. 기존 최종 확인 및 개인정보 미저장 규칙 유지.
- 관리자 요청 목록에 **가상 예약번호 검색**을 추가합니다. `DEMO-001` 같은 합성 ID의 대소문자 구분 없는 **포함 검색**만 허용하며, 이름·전화번호 등 실고객 정보 검색은 하지 않습니다. 상태 필터 및 기본·오름차순·최신순 정렬과 교집합으로 작동합니다. 결과 건수와 검색 적용 여부만 안내하며, 0건일 때 기존 빈 결과 안내가 표시됩니다. 검색어는 페이지 메모리의 상태 변수이며 localStorage나 서버에 저장하지 않습니다. 가상 데이터 초기화 시 비웁니다.
- 모든 새 버튼은 기존 미니멀 크림·그린 타이포그래피와 키보드 포커스 표준을 따릅니다. 푸터 표시는 `G3-36 STATIC DEMO`.

## QA
- 신규 `tests/g3-36-latest-time-admin-id-search-qa.cjs`: 실제 Chromium 및 Linux Playwright WebKit에서 (1) 날짜 전 버튼 비활성 및 빠른 날짜는 시간 미선택, (2) 가장 늦은 유효 슬롯/예약 미확정/빠른 시간으로 전환, (3) 키보드 Enter 및 날짜·수동 시간 변경 시 초기화, (4) 가상 최종 확인 이후에만 기록 생성/개인정보 미저장, (5) 검색 대소문자 및 0건 결과/검색 입력 포커스, (6) 상태 필터·정렬·전체 보기 교집합/기존 데이터 불변, (7) 초기화·새로고침 후 검색어 미보존, (8) axe WCAG 2.1 A/AA 자동 위반 0, 모바일 320/390px 가로 넘침과 JS 오류 0을 검사합니다.
- 기존 단일 워크플로의 **G3-12~35 전체 Chromium/axe/WebKit 회귀 검사 유지** 및 신규 검사 추가. G3-35 이전 기능 검사의 푸터 검사는 릴리스 숫자 35 이상을 허용하며 본래 기능 검증은 유지합니다.
- 전부 통과한 경우에만 PR squash 병합 및 GitHub Pages 배포 성공 확인.
