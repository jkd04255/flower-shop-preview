# 오후의 정원 G3-32 · 예약 최종 확인 상세·관리자 다음 처리 안내

## 기준과 변경 범위
- G3-31 `main` (f84d09403f5e9ba85766e43a467109309e2cd748) 기준, 기존 사진/가격/메인 히어로 `오늘의 꽃 만나기 ↗`/상품 카드/예약 3단계/가상 송금 흐름 및 관리자·캘린더 UX 보존.
- 고객의 최종 확인 화면에 **상품 금액**과 **전달 사항**을 추가합니다. 전달 사항이 비어 있으면 `없음`. 표시 시 `textContent`만 사용해 HTML 주입을 방지합니다. 고객 최종 확인 이전에 합성 요청은 생성하지 않습니다.
- 기존 마지막 확인 단계를 누르면 금액·전달 사항·이름·전화 등 확인 정보 DOM을 비우고 폼을 재설정합니다. 전달 사항은 **임시 브라우저 메모리와 리뷰 화면에만 존재하며 로컬 저장/서버 전송/관리자 표시하지 않습니다.** `reservationReviewDraft`에는 최종 확인까지 일시 저장하여 리뷰 후 필드가 변경되면 제출을 막습니다.
- 관리자 상세에 `다음 처리 안내 · 가상 시연` 문구를 추가하여 가상 송금 전/송금 표시 후 입금 체크 전/입금 체크 완료/정원 마감/예약 확정/수령 전/수령 완료/거절 상태에 따라 다음 조치가 다름을 알립니다. **단순 안내**, 버튼 활성화·입금 확인·상태 전이·저장 로직 일절 변경 없음.
- 크림·그린 디자인의 작은 안내 영역, 메모 줄바꿈 및 긴 글 안전 처리, 푸터 `G3-32 STATIC DEMO`.

2. `정보 수정하기`로 되돌아와 수정 후 다시 검토하면 해당 값이 갱신됩니다.
