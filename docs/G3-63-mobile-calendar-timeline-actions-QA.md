# G3-63 · 모바일 캘린더 예약 일정의 펼친 카드 처리 버튼 개선

## 문제와 설계
G3-62에서 접힌 일정 카드의 제목·상태·펼치기 영역을 정돈했지만, 펼친 카드 안에 표시되는 **기존 처리 버튼**은 폭 320~440px에서 11px의 작은 글씨와 낮은 터치 높이를 유지했습니다. 긴 ‘수령 전으로 변경’ 문구가 좁은 행에 몰려 가독성이 떨어지는 문제를 해결합니다.

## 변경
- 440px 이하에서 `.cal-timeline-actions button`의 최소 높이를 44px로 설정하고 글씨를 12px·600 굵기로 조정합니다.
- 액션 영역은 플렉스 줄바꿈을 허용합니다. 버튼이 2개면 공간에 따라 나란히 또는 세로로 배치되고, ‘상세 보기’ 하나만 있는 일정에는 남는 너비를 사용합니다.
- 텍스트를 강제로 한 줄로 고정하지 않아 2배 텍스트 확대 시에도 내용과 카드가 가로로 넘치지 않도록 합니다.
- 기존 승인 색상과 배경, 버튼 라벨, 비활성화 조건, 수령 상태 전환, 상세 화면 이동, `details` 펼치기/닫기 동작, 모든 합성 예약 데이터를 보존합니다.
- 441px 이상 기존 CSS 유지. 원본 꽃 사진·4:3 비율, **‘오늘의 꽃 만나기 ↗’**, 예약·조회·관리자·캘린더 기능 보존.

- 대기 중 예약의 단일 ‘상세 보기’ 버튼 너비/높이 검증, 클릭하면 기존 관리자 상세 화면으로 이동하며 같은 합성 예약 ID를 선택하는지 확인.
