# 오후의 정원 G3-55 — 모바일 관리자 예약 상태 필터 가로 레일

## 현황 및 디자인 판단
G3-54 배포 상태(`main 9c07b03`)에서 출발합니다. 기존 관리자 데모 화면의 예약 상태 필터 6개(전체, 입금 확인 전, 예약 확정, 수령 전, 수령 완료, 거절)가 320~390px 모바일에서 여러 줄로 줄바꿈되어 관리자 목록을 밀어내고 서로 경쟁하는 문제가 있습니다. 선택 항목을 제거하지 않고 시각적 밀도만 줄입니다.

## 구현 변경
- 600px 이하에서 6개 필터를 **한 줄 가로 스크롤 레일**로 표시합니다.
- 각 버튼의 높이 44px 이상, 선택 상태 대비, 키보드 포커스, `aria-pressed` 및 클릭 동작을 유지합니다.
- 좁은 화면에서는 다음 필터가 일부 보이는 자연스러운 가로 탐색을 사용하며 새 안내 문구·토글·선택지는 만들지 않습니다.
- 스크롤은 필터 내부에서만 발생해 페이지 전체가 가로로 움직이지 않아야 합니다. 기존 G3-21 reflow QA는 컨테이너 경계 안에 위치한 **의도된 가로 스크롤 레일 내부 항목만** 화면 밖 탈출 판단에서 제외합니다. 다른 요소와 문서 가로 넘침 검사는 계속 엄격하게 유지합니다.
- 데스크톱 원래의 줄바꿈 레이아웃, 버튼 텍스트와 수, 4건의 합성 예약 샘플, 필터 계산, 재설정, 사용자 정보 저장 정책을 변경하지 않습니다.
- 꽃 사진의 4:3 비율과 이미지 소스, 메인 **'오늘의 꽃 만나기 ↗'**, 꽃다발 상품 및 예약·조회·관리자·캘린더 흐름은 그대로 유지합니다.

## 테스트 및 배포 Gate
- 신규 `tests/g3-55-mobile-admin-filter-qa.cjs`: Chromium/WebKit 각 320·390·600·768·1280px에서 6개 버튼 유지, 모바일 한 줄·가로 스크롤·44px 터치, 데스크톱 원래 줄바꿈, 전체 페이지 가로 넘침 방지.
- 320px 맨 뒤 거절 필터 접근·선택 및 `aria-pressed`, 키보드 Enter로 전체 필터 복귀, 기존 합성 예약 및 로컬 저장 불변.
- 390px `axe-core` WCAG 2.1 AA 접근성 검사, 스크린샷 증거.
- **기존 전체 Chromium/Linux WebKit/axe 회귀 + G3-55 신규 테스트 전부 성공인 최신 커밋**에 대해서만 PR을 squash merge. 새 GitHub Pages 배포의 성공과 배포 SHA가 `main`과 같은지 확인.
