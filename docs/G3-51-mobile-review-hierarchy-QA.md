# 오후의 정원 G3-51 — 모바일 예약 최종 확인 화면의 정보 위계 개선

## 사용자 경험
G3-50에서 날짜·시간·연락처 입력을 한 열로 정리했습니다.
후속 작업에서는 고객이 정보를 다시 읽고 최종 확인하는 모바일 화면도 같은
절제된 디자인 원칙을 적용합니다. 정보를 없애거나 새 선택지는 만들지 않습니다.

## 디자인 변경
- 최종 확인 제목을 짧은 '예약 정보 확인'으로 변경.
- 중복 도입 안내를 압축하되, 최종 확인 전 가상 요청이 생성되지 않는다는 설명은 보존.
- 600px 이하에서 크림색 정보 카드의 무거운 박스/채움 대신 얇은 구분선을 사용.
- 내용 항목 7개는 모두 유지하며, 라벨/값 너비와 글씨 크기, 줄바꿈을 모바일에 맞게 조정.
- '정보 수정하기'는 보조 텍스트 버튼으로, '확인하고 가상 예약 요청하기'는 전폭 주요 버튼으로 배치.
- 버튼의 DOM 순서와 키보드 포커스 순서는 그대로 유지하며, 편집/최종 확정 로직 변경 없음.
- 601px 이상 데스크톱, 메인 이미지·메인 CTA '오늘의 꽃 만나기 ↗', 폰트·사진·입력 화면·예약 조회/관리자/캘린더 보존.

## 검증 및 배포
- Chromium, Linux WebKit, axe 및 기존 G3-12~50 회귀 전체 유지.
- 신규 `tests/g3-51-mobile-review-hierarchy-qa.cjs`는 320/390/600/768/1280px에서
  7개 확인 정보, 정확한 날짜/시간·가상 이름, 모바일 1열 버튼과 44px/50px 터치 크기,
  데스크톱 버튼 2열 유지, 오버플로 및 가상 예약 고지 검사.
- 320px 정보 수정 시 입력 보존, 390px 최종 확인 후 가상 예약 결과/이동 링크까지 검사.
- Chromium/WebKit 390px 최종 확인 캡처 보관.
- 전체 QA 통과한 PR만 squash merge하여 GitHub Pages 배포하고, 성공된 배포의 커밋 SHA 확인.
