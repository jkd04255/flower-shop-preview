# G3-62 · 모바일 일간 캘린더 예약 카드 가독성 및 펼치기 터치 영역

## 문제와 개선
일간 캘린더의 각 예약 일정은 기본적으로 접혀 있는 `details/summary` 카드입니다. 좁은 320~440px 화면에서 제목은 12px까지 줄고, 상태 표시가 옆으로 밀집하며, summary의 최소 높이는 32px에 불과했습니다.

## 구현
- **440px 이하** 예약 일정 카드의 기존 `summary` 조작 영역을 최소 48px로 확장합니다.
- 예약자 별칭·꽃다발 제목을 14px, 상태 배지 및 '상세' 표시를 12px로 조정합니다.
- 상태 배지/상세 표시를 오른쪽 수직 정렬로 배치하고, 글씨 확대 시 상태가 줄바꿈되도록 합니다.
- 열린 카드의 보조 예약 정보도 12px로 개선하지만 새 안내 문구나 버튼은 추가하지 않습니다.
- 441px 이상 기존 레이아웃 유지. 스케줄 시간축·상태 색상·작업 버튼·예약·조회·관리자·캘린더 로직 및 합성 데이터를 그대로 보존합니다.
- 꽃 사진·4:3 비율과 **'오늘의 꽃 만나기 ↗'** 문구는 변경하지 않습니다.

## 신규 QA
`tests/g3-62-mobile-calendar-timeline-summary-qa.cjs`를 기존 전체 브라우저 CI에 추가합니다.
- Chromium/Linux WebKit: 320·390·440·600·768·1280px 카드, 제목/상태/접힘 안내, 터치 영역, 반응형 변화, 문서 가로 넘침 검증.
- 기존 `details` 마우스·키보드 `Enter`로 열기/닫기, 예약번호 및 상세 버튼 보존, 합성 예약과 localStorage 불변.
- 390px axe-core WCAG 2.1 AA 0 위반, 스크린샷 및 JavaScript 오류 없음.
