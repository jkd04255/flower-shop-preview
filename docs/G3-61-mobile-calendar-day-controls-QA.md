# G3-61 · 모바일 캘린더 일간 날짜 이동 버튼 가독성 개선

## 문제와 범위
날짜를 선택한 일간 캘린더에서 ‘전날’, ‘다음날’, ‘새로고침’은 작은 휴대폰 화면에서 기존 CSS의 11px 작은 글씨와 짧은 조작 영역 때문에 조작하기 어렵습니다. G3-61은 **기존 4개 버튼의 표현만 개선**하며 추가 메뉴나 동작은 만들지 않습니다.

## 디자인 수정
- **최대 440px**에서 ‘월간 달력으로’ 버튼은 최소 높이 44px, 13px 글자로 조정합니다.
- 기존 3등분 ‘전날 / 다음날 / 새로고침’ 버튼을 각각 최소 높이 48px, 13px 글씨로 정돈합니다. 새로고침의 강조 녹색, 원래 둥근 버튼 스타일, 순서, 세 칸 배치를 유지합니다.
- 441px 이상의 태블릿 및 데스크톱 레이아웃은 변경하지 않습니다.
- 날짜 이동, 이전/다음 달, 새로고침, 예약 상태 필터, 스크린리더 안내, 합성 예약 데이터와 로컬 상태 저장 로직 전부 그대로 유지합니다.
- 기존 사진·모바일 4:3 비율, **‘오늘의 꽃 만나기 ↗’**, 예약·조회·관리자·캘린더 기능을 보존합니다.
