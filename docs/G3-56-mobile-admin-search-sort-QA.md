# 오후의 정원 · G3-56 모바일 관리자 검색/정렬 위계 개선

## 개선 대상 및 이유
G3-55에서 관리자 상태 필터 6개를 한 줄로 정돈한 뒤, 바로 아래의 예약번호 검색·정렬 영역은 기존의 `flex-wrap` 구조와 검색칸 최대 너비 200px로 인해 좁은 화면에서 검색 입력이 작고 정보가 흩어져 보입니다.

## 소규모 디자인 작업
- **최대 600px**에서 기존 검색 결과 건수 → 가상 예약번호 검색 입력/도움말 → 정렬 → 전체 보기 순서로 한 열 배치합니다.
- 검색 필드를 가용 너비 100%, 최소 높이 54px, 16px 글자로 조정해 iOS 자동 확대를 유발하는 작은 입력 글씨를 방지합니다.
- 기존 선택형 정렬의 높이 48px·15px 글씨, 검색 지우기·전체 보기 조작 영역은 최소 44px로 조정합니다.
- 기존 크림·녹색 팔레트와 글꼴, 버튼 스타일 유지. 새로운 메뉴·설명문·통계는 추가하지 않습니다.
- **601px 이상**에서 기존 관리 화면 구성과 검색 필드 최대 너비 200px 유지합니다.
- 검색값·정렬 옵션·필터 상태·검색 지우기 포커스 복귀·전체 보기·관리자 예약·캘린더·고객 조회 기능 및 합성 저장 정책은 모두 변경하지 않습니다.
- 기존 꽃 사진 원본과 모바일 4:3 비율, 메인 문구 **'오늘의 꽃 만나기 ↗'**를 보존합니다.
