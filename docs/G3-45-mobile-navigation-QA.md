# 오후의 정원 G3-45 — 모바일 메뉴·페이지 이동 UX

## 개선 배경
G3-44까지 모바일 메인 헤더의 기존 CSS는 가장 마지막 메뉴인 **예약 조회**만 보이게 했습니다.
고객이 상품을 찾으려면 화면 아래의 CTA까지 이동해야 하므로,
G3-45에서는 화면을 열자마자 **오늘의 꽃**과 **예약 조회** 두 가지 진입 경로를 모두 제공하도록 정리합니다.

## 변경 사항
- 모바일(최대 700px): **오늘의 꽃 / 예약 조회**를 44px 높이 이상의 간결한 헤더 링크로 항상 노출.
  - 예약 조회는 밝은 배경·진한 초록색 글씨로 구분하여 찾기 쉽게 함
  - 오늘의 꽃은 짙은 반투명 배경으로 사진과 겹쳐도 흰 글씨의 대비를 유지
  - 320~360px 작은 화면에서 여백·폰트 크기 추가 조정
- 데스크톱(701px 이상): **오늘의 꽃 / 최근 입고 / 매장 안내 / 예약 조회** 기존 네 링크 전부 유지.
- 헤더 메뉴에 접근성 이름(`쇼윈도 주요 메뉴`) 추가, 링크의 키보드 포커스 표시 강화.
- 상세/예약/예약 현황의 뒤로가기 링크를 모바일 44px 이상 터치 영역으로 제공.
- 새 메뉴 아이콘, 팝오버, JavaScript 메뉴 상태, 서버·외부 서비스·추가 서체는 도입하지 않음.
- 모바일에서 숨겨둔 최근 입고/매장 안내 내용과 실제 기존 앵커는 그대로 있어 스크롤로 접근 가능.

## 꼭 보존할 내용
- 메인 CTA **`오늘의 꽃 만나기 ↗`** 문구/링크와 사진, G3-42 Safari 초반 스크롤 및 peek.
- G3-43 Pretendard/한국어 제목 위계와 G3-44 승인된 꽃 사진 비율/채도/크롭.
- 기존 상세, 가상 예약, 가상 예약 조회, 관리자, 캘린더의 라우트 및 화면 기능.
- G2 전체 Gate HOLD와 은행·결제·실예약·DB/Auth·SMS·메일·고객 개인정보 저장 연동 금지.
- 실제 iPhone Safari / Instagram 인앱 브라우저 실기기 기능 확인은 아직 별도 미확인.

  - 화면 이동: 오늘의 꽃, 예약 조회, 조회 화면에서 매장 안내로 돌아가기,
