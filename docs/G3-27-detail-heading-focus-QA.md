# 오후의 정원 · G3-27 상품 상세 제목 파란 초점 테두리 수정 QA

- 기준선: 승인된 G3-26 `main`, 이전 G3-25 상품 카드·G3-24 최종 확인, G3-20~22 엄격 접근성 검사 및 단일 GitHub Actions 운영 정책.
- 증거: 2026-11-09 사용자가 제공한 **iPhone Instagram 앱 내 브라우저** 화면. `로지 모먼트` 제목 주변에 파란 사각형 테두리가 보이며, 페이지 진입 직후·스크롤 중에도 유지되는 현상.
- 운영 한계: **G2 전체 Gate HOLD**. 실고객 데이터·DB/Auth·실계좌·은행·메일·문자·과금/결제·실예약 기능 금지, 합성 데이터 정적 데모만 유지.

## 원인 분석 및 수정

1. 기존 `route()`의 `hashchange` 처리에서 상품 상세로 이동할 때 `#dTitle`에 `tabindex="-1"`을 지정하고 `.focus({preventScroll:true})`를 호출합니다. 이는 화면 전환 시 초점을 새 제목으로 이동해 보조기술 사용자의 문맥을 알려주려는 기존 접근성 구현입니다.
2. 제목 자체는 버튼·링크가 아닌 정적 `<h1>`이지만, 기본 브라우저/웹뷰 초점 스타일을 별도로 지정하지 않아 **지속되는 파란 outline이 발생할 수 있습니다**. 사용자 첨부 이미지와 코드 구조가 일치하지만, 실제 WebKit에서 자동 재현한 것은 아닙니다.
3. `#detail #dTitle[tabindex="-1"]:focus{outline:none}`을 추가해 **상품 상세 제목 한 곳에서만** 기본 브라우저 초점 사각형을 제거했습니다. JS 초점 이동과 `h1` 의미론은 유지하고, 실제 `#dReserve` 링크의 `:focus-visible` 2px 초점 표시도 그대로 유지합니다. 모든 요소에 `outline:none`을 적용하지 않습니다.
4. 처음 추가한 상품 상세 화면의 axe-core WCAG 자동 검사에서 **기존 연한 설명·스펙 정보 5곳의 대비 위반**(`#dStory`, `#dColor`, `#dLead`, `#dStatus`, 하단 `.muted`)이 확인됐습니다. 기존 G3-20 자동 검사 12개 시나리오가 이 화면의 해당 스타일을 전부 검사하지 않았던 부분입니다. 상품 상세 화면에 한정해 `.detailCopy .muted`와 `.detailCopy .spec span`의 글자색만 `#526154`로 조정해 대비를 확보했습니다. 사진·상품 이미지·가격·폰트·배치와 상호작용은 변경하지 않았습니다.
5. 릴리스 푸터를 `G3-27 STATIC DEMO`로 변경했습니다.
