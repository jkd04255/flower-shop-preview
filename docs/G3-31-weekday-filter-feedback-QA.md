# 오후의 정원 G3-31 · 픽업 요일과 관리자 필터 결과 안내

## 범위와 보존
- 기준: G3-30 병합 완료된 `main` (2083503be2cfbbdf4324af0358a8d3cea7fc1154).
- 고객 픽업 일정 미리보기에 날짜에 대응하는 **한국어 요일**을 표시합니다. 기존 일정/시간 선택, 영업일 검증, 최소 준비시간, 예약 3단계, 합성 데이터 저장/복원은 변경하지 않습니다.
- 관리자 목록의 기존 상태 필터 아래 **현재 선택 상태·표시 건수/전체 건수**를 표시합니다. 전체 이외의 필터일 때만 **전체 보기 ↗** 버튼을 보입니다. 버튼 클릭 시 기존 전체 필터를 활성화하고 숨겨지는 버튼 대신 전체 필터로 초점을 이동합니다.
- 대조 기준: 메인 히어로 '오늘의 꽃 만나기 ↗', 상품 카드 '상품 상세 보기 ↗', 기존 꽃 사진·가격, G3-28/29 iPhone 초점·확대 완화, G3-30 캘린더 날짜 바로가기, 관리자 입금 확인/확정/수령 상태 전환, 캘린더, 가상 입금, 개인정보 미저장 원칙 등 **모두 보존**합니다.
- 버전 표시는 `G3-31 STATIC DEMO`으로 바뀝니다.

## 접근성·안전
- 관리자 필터 건수는 `role=status`, `aria-live=polite`로 표시하며 변경된 내용일 때만 업데이트해 불필요한 중복 읽기를 줄입니다.
- '전체 보기' 키보드 `:focus-visible` 테두리 보존, 실행 후 '전체' 버튼으로 초점 복귀. 터치에서 비상호작용 제목에 파란 outline을 다시 넣지 않습니다.
- 관리자 필터/초기화는 표시만 바꾸며, 가상 예약 레코드의 상태·금액·이름·입금 여부를 건드리지 않습니다.
- **G2 전체 Gate HOLD**, 실예약·실고객 데이터·은행/실계좌·DB/Auth·문자/메일·실결제/과금·운영 API 등 실서비스 연동 절대 금지.

## 사용자 확인
1. 휴대폰에서 꽃다발을 선택한 뒤 픽업 날짜를 바꾸면 미리보기 요일이 따라 바뀌는지 확인합니다.
2. 관리자 데모에서 '수령 전' 상태를 누르면 표시 건수 0, '전체 보기' 버튼이 표시되는지 확인합니다.
3. '전체 보기'를 누르면 원래 전체 가상 목록으로 돌아옵니다. 실제 예약 및 고객정보는 사용하지 않습니다.
