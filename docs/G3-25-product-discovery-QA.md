# 오후의 정원 G3-25 · 상품 선택 유도 및 문의 전용 입고 소식 구분 QA

- **기준선:** G3-24 `main` 정적 시연 시안, G3-24 예약 최종 확인 및 이전 승인·QA 문서.
- **핵심 사용자 요구:** 메인 히어로의 **`오늘의 꽃 만나기 ↗`는 변경 금지**. 꽃다발 카드에서 클릭하여 상품을 보는 행동만 조금 더 명확하게 만들고, 실제 예약 가능한 꽃다발/문의 전용 입고 소식의 차이를 설명.
- **G2 전체 Gate HOLD:** 실제 고객 데이터·실예약·실계좌·은행·DB/Auth·메일·문자·과금·실결제/실송금·외부 연동을 추가하거나 활성화하지 않음.

## 변경 내용

1. 히어로 `<a class="call" href="#curation">오늘의 꽃 만나기 ↗</a>` **원문 및 링크를 바꾸지 않았습니다**. 사진·타이포그래피·간격·메인 구조도 유지했습니다.
2. 기존 `function card(p,i)`에서 상품별 `<a class="card" href="#/flower/...">` 안쪽에 `<span class="card-detail-link">상품 상세 보기 ↗</span>` 한 줄만 추가했습니다. **카드 전체가 하나의 링크**이며 중첩 버튼이나 새 클릭 영역을 만들지 않았습니다. 품절 상품도 상세 화면에서 상태를 확인할 수 있으므로 동일한 표시를 제공합니다.
3. 별도 CSS `g3-25-card-wayfinding`: 기존 카드 사진·상품명·가격 레이아웃을 변경하지 않고, 상세 보기 안내 글씨를 **12px·녹색·밑줄**로 최소 강조했습니다. 포커스·호버 색상만 조금 변경합니다.
4. `Today's selection` 안내: `오늘 가장 예쁜 세 가지` → **`오늘의 추천 꽃다발 · 사진을 눌러 상품 보기`**.
5. `Just arrived` 안내: **`최근 입고된 꽃 소식 · 문의 전용`** / **`예약 상품이 아니며, 문의만 가능합니다.`**. 기존 입고 상품의 `문의 전용` 배지는 유지하며 새 예약 기능을 만들지 않습니다.
6. 릴리스 푸터 표시만 `G3-24 STATIC DEMO` → `G3-25 STATIC DEMO`. 기존 G3-24 예약 최종 확인·가상 입금·관리자·달력·로컬 저장/복원 로직은 일절 수정하지 않습니다.
