# 오후의 정원 G3-49 — 빠른 픽업 선택 버튼 완전 제거

## 사용자 결정
G3-48에서 접혀 있던 **'다른 날짜·시간 빠르게 찾기'** 메뉴 및 그 안의
'가장 빠른 픽업 날짜 / 다음 픽업 가능일 / 가장 빠른 픽업 시간 / 가장 늦은 픽업 시간'
네 가지 버튼을 완전히 삭제합니다. 보조 선택 기능은 다시 제공하지 않습니다.

## 작업 범위
- 위 네 개 버튼과 접이식 도움말을 HTML에서 삭제.
- 관련 상태 출력 4개, 모든 버튼 이벤트 핸들러, 활성화 처리 및 불필요한 CSS 삭제.
- 기본 예약 화면은 **픽업 날짜 / 픽업 시간 / 선택한 일정 한 줄 / 예약자 정보**로 유지.
- 날짜를 변경하면 시간 선택이 초기화되고, 해당 날짜에 유효한 시간만 표시되는 핵심 동작 유지.
- 기존 예약 검증, 최종 확인, 가상 예약 접수, 상태 조회, 관리자/캘린더 테스트 유지.
- 과거 G3-34~37 회귀는 삭제된 버튼이 아닌 **직접 날짜·시간 입력**과 원래의 관리자 기능을 검증하도록 개선.
- G3-47/48 회귀도 버튼 **비노출이 아니라 DOM에서 완전한 부재**를 검증.
- 메인 CTA '오늘의 꽃 만나기 ↗', 사진·폰트·색감, 모바일 메뉴 및 기존 디자인 유지.
