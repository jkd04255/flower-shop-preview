# 오후의 정원 G3-44 — 꽃 사진 비율·크롭·색감 일관성

## 결정 사항
G3-43의 Pretendard·한국어 정보 위계와 기존 사진, 상품·가격·메인 문구를 유지하고,
CSS 이미지 프레임만 개선합니다. 사진 원본을 수정하거나 교체하지 않습니다.

- 고객 상품 카드 5개를 데스크톱/태블릿/모바일 공통 **4:5 꽃다발 사진** 비율로 맞춰
  상품별 사진 영역의 리듬을 통일합니다(기존 모바일 추천 1:1, 보조 상품 비율 혼재).
- 카드의 기존 `saturate(.78)` 필터를 `saturate(.96)`로 완화해 꽃의 색을
  지나치게 낮춰 보이지 않도록 합니다. 외부 사진을 다운로드·재가공하지 않습니다.
- 최근 입고 소식은 112×112px(모바일 86×86px) 정사각형 썸네일로 통일합니다.
- 상세·예약 화면 이미지에 `object-fit: cover` 및 상단 꽃다발을 의식한
  `object-position: center 45%`(모바일 상세 43%)를 적용합니다.
- 모바일 상세 상단 사진의 높이를 `clamp(390px,57svh,550px)`로 제한하여
  과도한 화면 점유를 피하고, 기존 상세·예약 경로를 보존합니다.
- 모바일 내 예약 조회 사진은 고정 높이 158px에서 **4:3 프레임**으로 변경해
  꽃다발이 더 많이 보이도록 합니다.
- 히어로 배경 사진 및 명암 오버레이는 그대로 보존하여 G3-21 대비 검사에 영향 없게 유지합니다.
