# G3-66 · 모바일 매장 안내의 가상 예약 조회 입력·버튼 정렬 개선

## 문제 및 단일 개선
매장 안내의 **'가상 예약 현황 조회'**는 기존 입력창과 제출 버튼을 `flex-wrap`으로 배치해, 폭 320~600px에서 한 행 또는 두 행으로 불규칙하게 표시될 수 있습니다. 폼의 발견 가능성·읽기 순서·터치 편의성 향상을 위해 동일한 내용을 모바일 한 열로 정돈합니다.

## 구현 범위
- **600px 이하**에서만 `#store .status-lookup-fields`를 1열 그리드로 변경합니다. ‘전화번호 뒷자리 4자리 (시연용)’ 입력창 다음에 ‘가상 예약 조회 ↗’ 버튼이 항상 한 행 전체 폭으로 표시됩니다.
- 라벨 글씨는 14px, 입력창은 16px(모바일 입력 확대 방지), 제출 버튼은 14px로 정돈합니다. 입력과 제출은 각각 최소 52px 높이입니다.
- 기존 배경·테두리·색상·본문 안내 및 초점 표시를 유지하며 새로운 문구·선택지·기능을 추가하지 않습니다.
- **601px 이상**은 기존 가로 `flex` 배치, 글자 크기, 버튼을 보존합니다.
- 가상 샘플 4자리 입력 검증, 별도 예약 현황 페이지 이동, 코드 미저장 정책과 모든 예약·조회·관리자·캘린더 기능은 그대로 둡니다.
- 기존 꽃 사진·4:3 비율, **‘오늘의 꽃 만나기 ↗’** 문구도 변경하지 않습니다.
