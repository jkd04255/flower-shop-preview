# 오후의 정원 G3-53 — 모바일 예약 현황 조회 입력 영역 정돈

## 범위
G3-52의 최신 `main`에서 진행합니다. 기존 예약 조회 화면의 동작을 그대로 유지하며,
600px 이하 모바일에서 검색 폼의 정보 위계만 개선합니다.

## 구현 내용
- 모바일 검색 카드의 채움색·외곽 박스를 제거하고 얇은 상하 구분선으로 교체.
- 입력 레이블을 14px로 명확히, 전화번호 뒷자리 가상 샘플 입력은 16px 및 높이 54px로 정리.
- **'예약 현황 확인 ↗'** 버튼을 유일한 54px 전폭 주요 동작으로 유지.
- 기존 샘플 코드·주의 문구는 버튼 아래 작은 안내로 보존.
- 601px 이상 데스크톱 검색 폼은 변경하지 않음.
- 가상 예약 상세 결과/상태 다시 확인/다른 예약 조회, 예약 검증 및 관리자·캘린더 로직 불변.
- 원본 사진·Pretendard·메인 '오늘의 꽃 만나기 ↗' 문구 변경 없음.
