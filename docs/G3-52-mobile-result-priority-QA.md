# 오후의 정원 G3-52 — 예약 완료 화면의 우선순위 정리

## 목표
G3-51의 입력·확인 화면에서 정돈된 디자인을 이어받아, 가상 예약 요청 결과 화면에서
네 개의 동일한 성격의 이동 버튼이 경쟁하지 않도록 합니다. 별도의 실제 예약·결제 연동은 하지 않습니다.

## 변경
- 가상 예약 정보를 표시한 직후 **'가상 예약 현황 보기 ↗'**를 유일한 강조 버튼으로 배치합니다.
- 다른 꽃다발 둘러보기, 꽃다발 상세로 돌아가기, 관리자 데모 보기 링크를 화면 하단의 작은 보조 링크로 정리합니다.
- 기존 네 목적지 모두 유지하고, 고객이 가장 필요한 확인 작업부터 할 수 있게 배치만 조정합니다.
- 600px 이하에서 정보 표의 레이블·값 가독성을 개선하고, 가상 송금 시연 카드는 과도한 채움 대신 낮은 시각적 강조로 처리합니다.
- 예약 상태, 계좌 미등록·실송금 금지, 가상 송금 표시 기능과 상태 알림은 삭제하지 않습니다.
- 데스크톱 구성과 메인 고정 CTA '오늘의 꽃 만나기 ↗', 꽃 사진·색감·폰트, 예약/조회/관리자/캘린더 로직을 보존합니다.

## 검증
- Chromium·Linux WebKit·axe 기존 전체 회귀.
- 신규 `tests/g3-52-mobile-result-priority-qa.cjs`에서 320/390/600/768/1280px 가상 예약 완료 화면으로 직접 진입해 실제 데이터와 주요 버튼 및 나머지 이동 링크를 확인합니다.
- 모바일 주요 버튼 전체 너비/최소 터치 크기, 가상 송금 카드와 보조 링크 순서, 보조 링크의 투명 배경, 데스크톱 오버플로 확인.
- 390px 가상 송금 표시 후 실제 은행 거래가 발생하지 않았다는 문구, 예약 현황 화면 이동 확인.
- G2 전체 Gate HOLD/실서비스 연동 금지와 실제 iPhone Safari·Instagram 인앱 브라우저 미검증 상태를 유지합니다.
- 전체 QA 성공 후 PR squash merge 및 GitHub Pages 배포 확인.
