# 오후의 정원 G3-48 — 픽업 날짜·시간 선택 간소화

## 문제
모바일 고객 화면에서 날짜·시간 필드 두 개 아래에 **4개의 빠른 선택 버튼**이
바로 노출되고, 각 버튼의 성공 메시지 두 줄과 선택 완료 요약까지
겹쳐 보여 **같은 정보를 반복**했습니다. 사용자는 무엇부터 눌러야 하는지 혼란스럽습니다.

## 해결
- 기본 화면: **픽업 날짜 → 픽업 시간 → 선택한 픽업 일정 한 줄 → 예약자 정보**.
- 기존 네 가지 빠른 선택 단축 기능은 삭제하거나 자동으로 실행하지 않고
  기본적으로 접힌 **'다른 날짜·시간 빠르게 찾기'** 도움말 안으로 이동합니다.
- 각 빠른 선택 버튼의 세부 상태 메시지도 접힌 도움말 안으로 이동해서
  **기본 예약 경로에서는 보이지 않게** 합니다.
- 사용자가 직접 날짜·시간을 입력하면 기존의 픽업 유효성 검사/시간 목록/선택 요약이 그대로 갱신됩니다.
- 기존 4개의 버튼 ID, 직접 입력 필드, 옵션 생성·검증 JavaScript 및 aria-live 안전 상태를 유지합니다.
- 도움말은 필요하면 키보드/터치로 펼치고 다시 접을 수 있습니다. 초기 상태는 모든 화면 크기에서 접힘.
- 메인 꽃 사진, 기존 디자인 토큰·타이포그래피와 페이지 이동, 예약/조회/관리자/캘린더 기능 유지.

- 과거 빠른 날짜/시간 선택 기능 시험(G3-34~37)은 **도움말을 의도적으로 펼친 뒤**
  동일 기능을 확인합니다. 시연 앱의 기본 접힌 설정은 별도 신규 검증이 담당합니다.
- 기존 G3-47 UI 검증은 기본 접힘 및 사용자의 명시적 펼침을 확인합니다.

  최종 픽업 요약 단일 표시, 접기/펼치기, 수평 오버플로와 자바스크립트 오류 여부 검사.
