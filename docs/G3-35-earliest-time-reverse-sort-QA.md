# 오후의 정원 G3-35 · 가장 빠른 픽업 시간·관리자 최신순 정렬

## 기준선과 범위
- G3-34의 `main` 병합 커밋 `5e287fc217bb12d531a17f12eaac939ba2ae1161` 기준.
- **고객:** G3-34의 `가장 빠른 픽업 날짜 선택 ↗`은 기존처럼 날짜만 고릅니다. 별개의 `가장 빠른 픽업 시간 선택 ↗` 버튼은 날짜가 유효하고 선택 가능한 시간이 있을 때만 활성화됩니다. 사용자가 명시적으로 누르면 기존 `pickupSlots()`에서 반환하는 현재 날짜의 첫 시간만 선택하고, `예약 확정 전 (가상)` 안내를 표시합니다. 날짜를 바꾸거나 비우면 이전 시간·안내를 초기화하며, 직접 시간을 고르면 빠른 선택 안내를 지웁니다. **자동 예약 요청/자동 확정 없음**.
- **관리자:** G3-34의 `기존 요청순`(기본)·`픽업 날짜순`에 `픽업 날짜 최신순`을 추가합니다. 날짜/시간/ID를 역순 정렬하며, 정렬은 기존 필터 결과 배열만 변경하고 `adminRequests` 및 저장 기록은 절대로 재배열하지 않습니다. 필터·전체 보기 시 정렬 선택을 유지하고 가상 데이터 초기화 시 기본값을 복구합니다.
- 기존 크림·그린 디자인, 사진, 꽃다발·가격, 메인 문구 **`오늘의 꽃 만나기 ↗`**, 카드 **`상품 상세 보기 ↗`**, 기존 G3-30~34 예약·관리자·캘린더 UX 및 G3-28/29 모바일 확대/초점 완화, 가상 계좌 및 3단계 최종 검토 전부 유지.
- 푸터만 `G3-35 STATIC DEMO`으로 표시합니다.

## 검증
- 신규 `tests/g3-35-earliest-time-admin-reverse-qa.cjs`: 실제 Chromium + Linux Playwright WebKit의 390px 터치 환경에서, (1) 날짜 선택 전 시간 버튼 비활성, (2) 날짜만 선택 시 시간 미선택, (3) 별도 버튼 클릭 후 첫 유효 시간 및 미확정 표시, (4) 날짜 변경/시간 직접 선택/날짜 삭제 시 이전 시간·안내 초기화, (5) 키보드 포커스/Enter, (6) 기존 리뷰·승인 이전 가상 예약 0건 및 승인 후 1건/개인정보 비저장, (7) 관리자 기본·날짜순·최신순·필터·전체 보기·초기화·현재 선택 카드·저장 원본 불변, (8) axe-core WCAG 2.1 A/AA 자동 위반 0, (9) 320/390px 넘침 0 및 JS 에러 없음.
- 기존 단일 워크플로 **G3-12~34 Chromium/axe/WebKit 테스트를 모두 유지하고**, G3-35 검증을 추가합니다. G3-34 테스트 푸터 검사는 G3-34 이상 버전을 허용하도록 변경해 기존 기능에 대한 검증 의미를 유지합니다.
- **전체 QA 통과할 경우에만** PR squash 병합 및 GitHub Pages 배포 성공을 확인합니다.

## 운영 보류
- **G2 전체 Gate HOLD** 유지. 실고객 정보·실예약·실계좌/실은행·DB/Auth·SMS/메일·실결제/과금·운영 API 등 **실서비스 연동 금지**.
- 자동화 Linux WebKit은 실제 iPhone Safari/Instagram 앱 내 브라우저의 검증이 아닙니다. 실제 iPhone 실기기 검증은 **미확인**.

## 사용자 테스트
1. 가상 꽃다발 예약에서 날짜 버튼을 눌러 날짜만 선택되며, 별도 시간 버튼을 눌러야 시간이 설정되는지 확인합니다.
2. 날짜를 바꾼 뒤 이전 시간이 남지 않는지 확인합니다.
3. 관리자 시연에서 `목록 정렬 → 픽업 날짜 최신순`과 상태 필터를 함께 사용해 봅니다.
