# 오후의 정원 G3-39 · 모바일 가독성 및 재조회 UX

## 기준선
- G3-38 `main`에서 시작한 작은 UI 개선입니다. 기존 사진 소스·상품·가격·메인 문구 **오늘의 꽃 만나기 ↗**와 상품 링크 **상품 상세 보기 ↗**, 예약·관리자·캘린더 기능을 보존합니다.
- 브라우저 내 `#/booking-status` 독립 조회 화면을 유지합니다. 팝업/실제 서비스/네트워크 호출을 추가하지 않습니다.

## 구현 사항
1. **작은 휴대폰 화면의 정보 배치 개선:** 600px 이하에서는 원본 꽃다발 사진이 좌측 좁은 칸에 밀리지 않고 카드 폭에 맞게 보입니다. 그 아래 상품명·픽업 날짜/시간·금액·예약번호 등의 값은 **2열로 넓게 정리**하고, 날짜·시간 값에 우선 시각 강조를 줍니다. 단계 표시는 4칸의 빽빽한 가로형에서 **2×2 그리드**로 바꾸어 한 줄 글자를 12px로 확보합니다. 기존 크림·그린 스타일, PC의 좌측 사진+우측 2열 목록 레이아웃은 보존합니다.
2. **다른 예약 재조회:** 가상 예약 상세를 확인하면 카드 아래에 `다른 예약 조회 ↗` 버튼을 제공합니다. 누르면 결과와 메모리 내 현재 조회 선택만 해제하고 기존 4자리 입력창으로 키보드 포커스를 반환합니다. 입력된 예시 번호는 남기지 않습니다. 샘플/가상 예약 저장 기록 및 관리 상태는 바꾸지 않습니다.
3. **잘못된 코드에서 오래된 카드 삭제:** 4자리 형식이 아닌 입력을 제출하면 직전 사용자의 카드가 남지 않도록 화면과 현재 선택을 비웁니다. 4자리이지만 일치하지 않는 번호 역시 기존과 같이 '없음' 안내만 표시합니다.
4. **개인정보/신뢰 경계:** 4자리 입력은 기존과 같이 탭 메모리에서만 사용하며 URL/localStorage/서버로 전송하지 않습니다. 실제 예약 조회와 본인확인은 불가능합니다. 가상 계좌번호 `000-0000-0000`은 실제 송금 불가능한 시연용 값으로 유지합니다.

## 자동 QA
- 기존 단일 GitHub Actions의 **G3-12~38 Chromium/axe/WebKit 전체 회귀**는 제거·우회하지 않고 전부 실행합니다. G3-38 테스트에서 푸터 버전 검사를 38 이상 허용하도록 조정했으며 원래의 기능 검사는 모두 보존합니다.
- 신규 `tests/g3-39-status-mobile-relookup-qa.cjs`: 실제 Chromium과 Linux WebKit의 320/390px 모바일 카드에서 사진 위치·2열 데이터·2×2 단계·가로 넘침·입력 폰트 확인, 재조회 후 카드 제거·포커스, 다른 샘플 예약 상태, 잘못된 번호의 직전 카드 제거, 0건 상태, 새로고침 시 번호/결과 초기화, PC의 원래 레이아웃 유지, axe WCAG 2.1 A/AA 자동 위반 0, URL/저장소 비누출 및 JS 에러 0.
- **전체 QA 통과 후에만** PR을 `main`에 squash 병합하고 GitHub Pages의 동일 커밋 배포 성공을 확인합니다.

## 유지 정책
- **G2 전체 Gate HOLD**, 실제 은행/계좌/결제·입금 연동·실고객 예약/조회·Auth/DB·문자/메일·개인정보 저장 및 운영 API 연동 금지.
- Playwright Linux WebKit 검사는 **실제 iPhone Instagram 앱 내 브라우저 실기기 검증이 아닙니다.** 해당 항목은 미확인으로 유지합니다.
