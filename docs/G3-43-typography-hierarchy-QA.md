# 오후의 정원 G3-43 — 글꼴·정보 위계 개선

## 목표
G3-42의 배포 기준으로, 고객이 꽃을 탐색할 때에는 사진과 한국어 제목을 먼저 읽고,
상세·예약·조회·운영 화면에서도 같은 Pretendard 기반의 정보 위계를 느끼도록 조정합니다.
제품 사진·동작·예약 처리·메인 고정 문구와 기존 G2 Gate HOLD는 보존합니다.

## 디자인 시스템(수정 범위)
- 폰트 자체 교체 **없음**: 승인된 Pretendard Variable 및 기존 폰트 fallback 유지.
- 홈의 4개 섹션에서 영어를 11~12px 보조 레이블로 내려놓고 한국어 제목을 기본 heading으로 강조.
  - Today's selection. → 오늘의 꽃
  - Just arrived. → 새로 들어온 꽃
  - Everyday flowers. → 매일의 꽃다발
  - Visit the atelier. → 매장 안내
- 영어 원문도 보존해 분위기는 유지하되, 한국어 제목은 실사용자에게 직관적인 탐색 단서가 됩니다.
- 제목 크기를 화면 폭에 따라 조절(모바일 34~45px), 본문 안내 14~15px,
  상품명 17px/가격 15px/세부 설명 13px, 예약 버튼 14~15px 수준으로 정돈.
- 상품 상세/예약/조회/관리자/캘린더의 제목 굵기와 본문 정보 대비를 통일.
- 새 외부 서체/이미지/라이브러리나 서버·DB 의존성을 추가하지 않았습니다.

## 보존 사항
- 메인 `오늘의 꽃 만나기 ↗` 문구 고정, 히어로 등장 애니메이션과 G3-42 Safari 초기 스크롤 개선 보존.
- 기존 모든 상품·가격·사진 URL·사진 크롭 규칙·예약 상태 로직·가상 데이터 유지.
- 예약 현황 조회·관리자·달력 및 가상 입금 상태 기능 보존.
- **G2 전체 Gate HOLD / 실예약·은행·결제·DB/Auth·SMS·메일·실고객 개인정보 연동 금지**.
- iPhone Safari 및 Instagram 인앱 브라우저 실기기 검증은 별도이며 자동 QA로 대체하지 않습니다.
