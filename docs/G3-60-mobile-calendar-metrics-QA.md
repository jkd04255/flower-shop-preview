# G3-60 · 소형 모바일 캘린더 픽업 운영 현황 가독성

## UI/UX 개선 선정
캘린더 일간 상세 화면의 **픽업 운영 현황**은 다섯 개(전체, 입금 전, 예약 확정, 수령 전, 수령 완료) 지표를 좁은 320~390px에도 한 줄에 표시하여 상태명이 9px까지 줄었습니다. 손가락 조작 영역은 아니지만 가독성이 낮고, G3-59의 하단 필터 개선과 대조됩니다.

## 실제 변경
- 폭 **440px 이하**에서만 다섯 지표를 3열·2행으로 재배치합니다. 첫 번째 ‘전체’는 2열 차지, 나머지 네 지표는 기존 순서대로 배치합니다.
- 각 상태명 12px, 숫자 23px, 조용한 녹색 배경의 ‘전체’ 위계로 변경합니다. 기존 색채·폰트·라운딩 계열 유지.
- 지표 내용과 산술·상태 로직, 가로 스크롤 5개 필터(G3-59), 월간·일간 캘린더 및 다른 화면을 변경하지 않습니다.
- 441px 이상은 기존의 다섯 칸 한 줄 레이아웃을 유지합니다. 새 텍스트, 버튼, 인터랙션은 추가하지 않습니다.
- 원본 꽃 사진·4:3 비율, **‘오늘의 꽃 만나기 ↗’**, 예약·조회·관리자·캘린더 기능 전부 보존합니다.
