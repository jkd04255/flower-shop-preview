# 오후의 정원 G3-50 — 모바일 예약 입력 가독성

## 문제와 선택
G3-49에서 불필요한 픽업 보조 버튼을 없앤 뒤에도, 390px 이하 모바일 화면에서는
픽업 날짜/시간과 예약자 이름/연락처가 두 열로 놓여 네이티브 날짜 입력 내용과 예시 전화번호가 좁게 보였습니다.
입력 폰트 15px는 일부 실제 iPhone Safari에서 포커스 시 자동 확대를 유발할 수 있습니다.

이번 작업은 **필드를 추가하지 않고 입력 칸을 넓혀 한 줄에 하나씩 배치**하는 소규모 정돈입니다.

## UI 변경
- 600px 이하: 픽업 날짜 → 픽업 시간 → 이름 → 연락처 입력을 세로 한 열로 표시합니다.
- 날짜/시간/이름/전화번호/전달사항의 입력 폰트를 16px로 통일하고, 텍스트 입력 높이를 최소 52px로 확보합니다.
- 필드의 레이블은 모바일에서 14px로, 선택한 픽업 요약은 14px로 가독성을 높입니다.
- 길었던 픽업 운영 안내를 **'픽업 가능: 평일 11:00–19:00 · 1시간 간격 · 14일 이내 · 상품별 준비시간 적용'**으로 정리합니다.
- 601px 이상 데스크톱의 2열 그리드, 원본 사진/색감, 브랜드 텍스트와 화면 전환은 변경하지 않습니다.
- 실제 날짜·시간 계산, 유효성 검사, 최종 확인, 가상 요청, 예약 조회 및 관리자/캘린더는 그대로 유지합니다.
