# G3-69 · 사장용 콘텐츠 관리 화면 + 실시간 고객 페이지 미리보기

## 요구사항
- 가로 화면의 좌측 편집 / 우측 실제 고객 페이지 미리보기.
- 사장이 메인 사진, 오늘의 꽃과 일반 꽃다발 사진, 상품명·가격·설명·예약 가능 여부와 **상품 수**를 바꾸고, 가게명·주소·전화번호·운영시간·픽업 안내를 조절.
- 입력과 사진 선택 즉시 오른쪽에 반영. 상품 추가·삭제와 오늘의 꽃/일반 상품 이동을 지원.
- 기존 브랜드 사진·사진 비율(4:3 포함), ‘오늘의 꽃 만나기 ↗’, 예약/조회/관리자/캘린더 원형 보존.

## 설계와 실제 구현
- `owner-studio.html`: **가로 2분할 관리 워크스페이스**. 좌측 편집, 우측 `index.html?owner-preview=1#top` 을 불러오는 실제 고객 화면 `iframe`. 폭 830px 이하에선 편집 위·고객 화면 아래로 순차 정렬.
- `assets/owner-studio.css`: 기존 크림·세이지·차콜 기반 편집형 UI, 키보드 포커스, 사진 썸네일과 상품 그룹.
- `assets/owner-studio.js`: 기존 고객 페이지에서 메시지로 상품/매장 기준 데이터를 가져와 별도 복사한 편집 Draft 모델에 반영. 입력값 실시간 전송, 상품 추가/삭제·노출 위치 변경 및 원상 복원, 최대 30개 상품.
- `assets/owner-preview.js`: 같은 출처 메시지 검증 뒤 실제 고객 페이지 **P/U 렌더링 데이터와 본문·사진만** 미리보기 안에서 수정. 기존 3개/2개 상품 분류의 **미리보기에서만** 확장 가능. 가격·사진·문자열 검증, DOM 텍스트를 안전하게 삽입해 임의 HTML 실행을 방지.
- 기존 관리자 화면에서 `상품·매장 정보 편집 데모 ↗` 링크로 접근. 원래 예약 관리자 기능과 고객 페이지는 변경하지 않음.
- 이미지 업로드는 3MB 이하 JPG·PNG·WebP를 브라우저 `FileReader`로 읽어 현재 창에만 적용. SVG와 초대형 파일을 차단.

## 중요한 G2 Gate
이는 **공개 관리 시스템이 아닌 임시 시연 도구**입니다. 관리자 인증도 없으며 외부 사용자가 이 화면을 열어볼 수 있습니다. 따라서 해당 편집기는 실제 공개 사이트, 서버 또는 다른 방문자의 고객 페이지에 어떠한 수정도 게시하지 않습니다.
- 폼·사진·상품 설정은 브라우저 현재 탭의 **RAM에만 보관**, 새로고침하면 초기화. `localStorage`, IndexedDB, 서버 업로드, API, 외부 계정/결제 연동 없음.
- 미리보기 `iframe`에서는 기존 합성 예약 저장/복원도 차단해 공개 데모의 `localStorage`와 분리. 일반 고객 페이지에는 원래 가상 예약 기능 그대로 유지.
- 정식 게시·상품 카탈로그 영속 저장·로그인·역할별 권한·서버 검증·미디어 저장/처리 기능은 **G2 HOLD 해제 뒤 별도 승인/설계 필요**.
- 실예약·계좌·송금·결제·실고객 개인정보 영속화 금지, 사진 실제 게시 금지.

## 새 QA 및 합격 기준

- Chromium/Linux WebKit의 데스크톱 가로 1440·1280·1080px **편집 좌/고객 페이지 우 2분할**, 모바일 780·390·320px 수직 대응 및 가로 넘침 없음.
- 원본 고객 페이지를 iframe에 그대로 로딩했는지, 원본 사진과 고정 CTA, 기본 상품 3개 + 2개를 검증.
- 실시간 가게명·주소·전화·운영시간·픽업안내, 메인/상품 사진 파일 선택 및 SVG 거부, 상품명/가격 수정, 추천/일반 이동, 추가·삭제/개수, 미리보기 반영.
- 초기화 및 새로고침 이후 Draft 폐기, 독립 고객 페이지 무변경, localStorage 및 가상 예약 불변.
- axe WCAG2.1 AA 0 위반, 런타임 오류·증거 스크린샷.
- 기존 전체 Chromium/WebKit/axe 회귀는 **삭제·스킵·약화하지 않음**.
