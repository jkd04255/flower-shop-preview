# 오후의 정원 G3-33 · 고객 전달 사항 글자 수·관리자 픽업 시간대 가상 확정 수

## 기준 및 범위
- 기준: G3-32 병합된 `main` (`eb5fe4ffe156aa9d87d7b38bdb1f1ca4584d5bf5`).
- **고객:** 전달 사항(선택) 텍스트 영역 아래에 현재 입력 길이 `n / 120자 · 가상 시연용`을 표시합니다. 입력·편집 중 자동 변경되고, 가상 예약 완료 및 다른 상품을 선택하면 0자로 돌아갑니다. `aria-describedby`로 입력 영역과 글자 수를 연결합니다. 글자 제한(120자)과 기존 전송/저장 정책은 변경하지 않습니다.
- **관리자:** 가상 예약 상세의 픽업 시간 옆에 해당 시간대 **가상 확정 건수 / 가상 정원(3건)** 정보를 표시합니다. 기존 `demoConfirmedSlotCount`와 `DEMO_SLOT_CAPACITY`를 읽기만 하며, 거절된 요청에는 표시하지 않습니다. 예약 확정·수령 전·수령 완료 상태를 포함한 기존 용량 계산 규칙이나 상태 전이 로직은 변경하지 않습니다.
- 기존 디자인, 사진, 상품/가격, 메인 `오늘의 꽃 만나기 ↗`, 상품 카드 `상품 상세 보기 ↗`, 3단계 최종 확인, G3-30~32 UX, 관리자/캘린더, 가상 계좌·입금 시연 보존. 푸터만 `G3-33 STATIC DEMO`으로 갱신합니다.

## 검증
- 새 `tests/g3-33-memo-slot-qa.cjs`는 Chromium 및 Linux Playwright WebKit에서 모바일 390px 및 320px으로 글자 수 0·6·120, 리뷰·수정·완료 시 소거, 로컬스토리지에 메모 미저장, 관리자 대기 0/3·확정 1/3·거절 제외, 기존 수동 확정 후 1/3 갱신, 캘린더 바로가기 유지, axe WCAG 2.1 A/AA 자동 위반 0, JS 오류/가로 넘침 없음 검사.
- 기존 단일 워크플로우 G3-12~32 Chromium/axe/WebKit 게이트는 모두 유지합니다. G3-32의 푸터 버전 검사는 이전처럼 하위 범위의 의미(32 이상)를 보존하면서 신규 릴리스에서 동작하도록 하며, 제거하거나 약화하지 않습니다.
