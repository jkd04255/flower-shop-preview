- 기준선: G3-29 병합된 `main` (`1b420a4e12b6baba1a643c544489d6c79a1336a7`).
- **고객 예약 결정과 관리자 처리의 위치 탐색만 개선**합니다. 디자인, 사진, 상품/가격, 메인 ‘오늘의 꽃 만나기 ↗’, ‘상품 상세 보기 ↗’, 예약 3단계, 입금 조건, 가상 데이터 저장과 관리자 상태 처리 전이 모두 보존합니다.
- **G2 전체 Gate HOLD**, 실제 고객/예약/DB/Auth/계좌·은행·문자·메일·과금·결제 API 연동 금지. 모든 내용은 로컬 합성 시연입니다.

## G3-30 변경 사항
1. 고객 픽업 날짜를 선택하면 폼 아래 작은 크림·그린 안내가 나타나 **선택한 날짜와 아직 선택하지 않은 시간**을 알려줍니다. 시간 선택 후에는 **날짜·시간·예약 확정 전 (가상)**으로 즉시 업데이트합니다. 날짜를 변경하거나 지우면 이전 시간이 남지 않고, 이용 불가능한 날짜에는 숨깁니다. 이름·전화번호 등 개인정보는 안내에 표시하거나 저장하지 않습니다.
2. 관리자 상세 화면에 가상 요청의 픽업 날짜로 이동하는 **‘이 예약 날짜를 캘린더에서 보기 ↗’** 버튼을 추가합니다. 버튼을 누르면 기존 캘린더의 해당 날짜 **일간 보기**와 전체 상태 필터가 열립니다. 달력에서 제외되는 거절 상태에는 버튼을 표시하지 않습니다. 예약의 데이터나 상태를 수정하지 않습니다.
3. 키보드 초점 테두리를 기존처럼 유지합니다. `G3-30 STATIC DEMO`으로 푸터만 갱신했습니다.

## 수동 사용자 확인
1. 가상 꽃다발 상세 → 날짜 선택 → 시간 선택 → 날짜 변경에서 안내가 맞는지 확인합니다.
2. 가상 요청 완료 뒤 관리자 데모에서 해당 카드 선택 → ‘이 예약 날짜를 캘린더에서 보기 ↗’ → 그 날짜의 예약 일정 표시를 확인합니다.
3. 실제 이름·번호나 계좌 정보는 입력하지 마세요. 이 사이트는 실제 주문을 받지 않습니다.
