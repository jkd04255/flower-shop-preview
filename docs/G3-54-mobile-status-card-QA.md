# 오후의 정원 · G3-54 모바일 예약 현황 결과 카드 정보 위계

## 목적
G3-53에서 예약 현황 조회 입력을 정돈한 다음, 고객이 샘플을 조회했을 때
**상품 이름 → 상태 → 픽업 날짜/시간 → 꽃 사진 → 나머지 정보 → 진행 단계 → 가상 입금 안내**
순서로 읽히는 결과 카드를 만듭니다. 새 기능이나 선택지는 추가하지 않습니다.

## 적용 범위
- 600px 이하 모바일 카드에만 편집 디자인형 간격과 정돈된 글자 위계 적용.
- 꽃다발명과 상태 배지를 세로로 배치하여 좁은 320px에서도 서로 경쟁하지 않게 함.
- 픽업 날짜·시간 두 열은 그대로 유지하며 부드러운 연녹색 강조 배경, 17px 값을 적용.
- 기존 꽃 사진을 유지하고 원본 소스·크롭 규칙을 보존하면서 모바일 사진 높이를 150px로 통일.
- 상세 정보 6개와 진행 단계 4개를 그대로 유지. 가상 입금 안내의 진한 면을 약한 배경으로 낮춤.
- **가상 계좌 예시(000-0000-0000)와 송금 금지 경고는 절대 제거하지 않음.**
- 601px 이상 데스크톱, 메인 카피 '오늘의 꽃 만나기 ↗', 원본 사진, 홈/예약/관리자/캘린더 모두 불변.
