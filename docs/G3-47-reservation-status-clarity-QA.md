# 오후의 정원 G3-47 — 예약·예약 현황 화면 정보 위계 정리

## 목표
G3-46 모바일 헤더 디자인을 유지하고, 예약 화면에 반복되는 긴 안내와
일정 빠른 선택 링크 네 개가 흩어져 있는 문제를 개선합니다.
중요한 가상 시연 및 개인정보·송금 금지 안내는 삭제하지 않습니다.

## 사용자 화면 변경
- 예약 상단 안내를 한 문장과 간결한 가상 시연 주의 문구로 축약합니다.
- 영업시간/픽업시간/14일 이내 및 준비시간 정책을 한 줄의 정보로 간결하게 제공하되 조건값은 변경하지 않습니다.
- 빠른 픽업 날짜·시간 버튼 네 개를 **두 열의 보조 동작 영역**으로 묶고 모바일 320px에서는 한 열로 표시합니다.
  원본 버튼 ID와 문구·disabled 상태·실행 코드는 모두 그대로 둡니다.
- 송금 확인 전 예약 확정 불가 안내, 실송금 금지, 예시 개인정보 사용 및 서버 전송 없음 문구를 보존하며 축약합니다.
- 최종 확인 설명을 간결하게 정리하고, 결과의 두 번째 이하 이동 버튼은 얇은 밑줄형 링크로 시각적 강조를 낮춥니다.
- 예약 현황의 설명과 검색 카드 여백을 줄여 **4자리 입력 → 현황 확인**을 먼저 볼 수 있게 합니다.
- 실제 고객 조회 기능이 아니며 개인정보 보호 설계가 필요하다는 안내는 그대로 둡니다.
