## 재현 가능한 문제와 수정

1. **모바일 320px 일간 캘린더 버튼 글자 줄바꿈:** 기존 `cal-day-nav` 단일 flex 줄에서 버튼이 가로로 압축되면서 버튼 높이 약 47~48px. 440px 이하에서는 일간 탐색을 두 줄로 배치하고 3개 동작 버튼을 균등하게 나눠 약 35px 단일 줄로 표시. 7일 주간 날짜 원형 배지도 좁은 열 너비 이하로 제한. 전체 페이지 가로 스크롤은 변경 전에도 관측되지 않았음.
2. **입금 확인 체크박스 초점 상실:** 체크 후 `renderAdminDemo()`가 체크박스를 다시 만드는 기존 동작에서 초점이 원래 노드와 함께 사라짐. 같은 항목의 새 체크박스로 초점 복원.
3. **월간→일간 캘린더 전환 초점:** 선택한 달력 날짜 버튼이 숨겨지면 읽기·키보드 초점을 새 날짜 제목으로 이동. 월간으로 돌아가면 원래 날짜 버튼에 초점 복원. 일간의 전날/다음날 버튼은 초점 이동을 강제하지 않음.
4. **해시 라우팅 초점:** 꽃다발 상세/예약/관리자/캘린더 내비게이션 전환 후 진입 화면의 제목을 키보드 초점 대상으로 제공. 일반 `#curation` 스크롤은 기존대로 유지.
5. 날짜별 예약 목록에 명시적 `region` 역할 및 날짜 제목 연결 추가.

## 회귀 주의 사항

- 이 시안은 `localStorage` 기반 가상 예약 현황입니다. 실제 사용에는 관리자 인증, 최소권한, 서버 측 시간/정원 검증과 원자 트랜잭션이 필요하며 G4에서 검증해야 합니다.
- 시간당 3건 상태 계산: CONFIRMED/READY/COMPLETED만 정원에 포함하고 PENDING·거절은 포함하지 않습니다.
