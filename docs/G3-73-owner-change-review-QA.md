## 구현 범위
- `owner-studio.html`: 기본 시연 데이터 대비 현재 편집 결과를 확인하는 접고 펼칠 수 있는 **편집 변경사항** 패널. 초기에는 접힌 상태이며 수정 건수는 계속 확인 가능.
- `assets/owner-studio.js`: 매장 이름·주소·전화·영업시간·픽업 안내, 메인 사진, 판매 상품의 추가·삭제·분류 이동·상품명/설명/가격/색상/준비시간/판매 상태/사진, **기존 진열 상품 순서**를 초기 원본과 비교. 변경이 취소되거나 원본으로 복원되면 자동으로 목록에서 제외. 한 상품의 여러 편집 항목은 하나의 그룹으로 표시.
  - 사진 URL(data URL 포함)은 비교에만 쓰고 화면에는 **사진 교체**라고 표시하며, 파일 데이터/base64를 사람용 변경사항 목록에 절대 렌더링하지 않음.
  - 가격 `39,000`과 `39000`은 동일하게 취급.
  - 상품 삭제나 진열 분류 이동 자체는 별개의 **진열 순서 변경**으로 잘못 집계하지 않음. 원본과 편집 후 양쪽 그룹 모두에 남은 상품의 상대 순서만 비교.
  - 모든 항목은 DOM `textContent`만 사용. 사용자 입력을 HTML로 삽입하거나 외부에 전송하지 않음.
  - 변경사항 패널은 **읽기 전용**, 실제 반영/게시/저장/실예약을 수행하는 버튼을 추가하지 않음. 기존 즉시 고객 iframe 미리보기, 초기화, 삭제 복구, 사진 업로드 경합 처리는 보존.
- `assets/owner-studio.css`: 승인된 크림/세이지/차콜 편집형 UI, 데스크톱 좌우 분할 및 모바일 위아래 재배치, 접근 가능한 44px 조작 버튼 유지.
- `tests/g3-73-owner-change-review-qa.cjs`: Chromium + WebKit에서 최초 0건, 키보드 확장, 가게 정보 수정/원복, 메인 사진 변경/원복, 가격 표기 동등성, **사진·상품명·가격 4회 반복 수정**, 설명+상태 묶음 비교, 진열 이동/취소, 분류 이동, 상품 추가·삭제·실행 취소·초기화, HTML 삽입 방지, 1440·1080·780·390·320px, axe WCAG 2.1 AA, 독립 고객 화면/LocalStorage 보존, 새로고침에 따른 초기화 검증.
- `.github/workflows/g3-17-browser-qa.yml`: G3-73 테스트 **추가**; G3-12~72 기존 모든 회귀 단계 삭제·축소하지 않음.
