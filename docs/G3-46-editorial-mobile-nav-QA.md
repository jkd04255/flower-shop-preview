# 오후의 정원 G3-46 — 모바일 헤더 디자인 정돈

## 문제
G3-45에서 모바일 접근성은 좋아졌지만 상단의 '오늘의 꽃'과 '예약 조회'를
짙은 초록색 / 크림색 직사각형 버튼으로 표시해 사진 중심의 감성적인
쇼윈도 디자인과 시각적으로 충돌합니다.

## 선택한 디자인
- **편집디자인(Editorial)형 텍스트 메뉴**: 두 개의 버튼 배경·테두리·둥근 모서리·상반된 강조색 제거.
- 흰색 Pretendard 11.5~12px, 중간 굵기, 작은 자간 및 각 링크 아래 1px 헤어라인.
- 꽃 사진 위 텍스트의 가독성을 위해 **전체 헤더에만 어두운 그라데이션 스크림** 적용.
  개별 버튼처럼 보이는 박스는 다시 만들지 않습니다.
- 320px~700px에서도 브랜드와 메뉴가 겹치지 않게 기존 G3-45 반응형 레이아웃 및
  44px 터치 높이 유지.
- 701px 이상 데스크톱 헤더와 가상 예약 조회 등의 다른 화면 메뉴는 변경 없음.

## 보존
- 모바일 `오늘의 꽃` → `#curation`, `예약 조회` → `#/booking-status` 경로.
- 메인 `오늘의 꽃 만나기 ↗` CTA의 정확한 글귀와 href, G3-42 히어로 스크롤 동작.
- G3-43 글꼴·G3-44 사진 및 모든 상품/예약/조회/관리자/캘린더 기능.
- G2 전체 Gate HOLD. **실제 예약·송금·은행·결제·DB/Auth·개인정보 저장·SMS/메일 등 연결 금지**.
- iPhone Safari/Instagram 앱 내 브라우저 실기기 QA는 미확인 상태로 유지.

## 품질 게이트
- Chromium, Linux WebKit, axe 및 기존 G3-12~45 전체 회귀 성공 시에만 main에 병합.
- 신규 `tests/g3-46-editorial-mobile-nav-qa.cjs`: 320/360/390/700/768/1280px에서
  박스 배경·테두리 제거, 흰색 글씨, 미세 밑줄, 헤더 스크림,
  가로 넘침·브랜드/히어로 충돌 없음, 44px 터치 영역, 데스크톱 디자인 보존 검사.
- Chromium/WebKit 모바일 390px 증빙 화면 캡처를 기존 CI 아티팩트에 포함.
