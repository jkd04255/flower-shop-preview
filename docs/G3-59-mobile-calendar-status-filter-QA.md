# G3-59 · 모바일 캘린더 예약 상태 필터 한 줄 정돈

## 변경 대상
월간 달력에서 날짜를 누른 뒤 나오는 **일간 캘린더의 다섯 상태별 필터**가 320~390px 모바일에서 여러 줄로 펼쳐져 아래 시간표가 밀리는 문제를 개선합니다. 상태나 예약 자료를 줄이지 않고 화면의 시각적 밀도만 줄입니다.

## 범위
- 600px 이하에서 기존 다섯 필터(전체, 입금 전, 예약 확정, 수령 전, 수령 완료)를 가로 스크롤 한 줄로 표시합니다.
- 버튼은 최소 44px 높이, 최소 12px 폰트로 유지하며 선택 상태, 동적으로 표시되는 건수, 키보드 포커스, 클릭·상태 전이 및 정렬은 원형 그대로 보존합니다.
- 기존 크림/그린 팔레트·캘린더 시간축·상태 색상·접이식 상세·월간 달력·관리자·예약/조회 기능을 보존합니다.
- 추가 버튼, 안내 문구, 새 예약 기능 없음. 601px 이상 레이아웃은 그대로입니다.
- G3-21 엄격 reflow QA는 **경계가 보이는 독립 스크롤 컨테이너 내부 요소만** 문서 밖 탈출로 오인하지 않도록 인식 범위를 확장합니다. 실제 문서 overflow와 일반 버튼 탈출 검사는 그대로 유지합니다.
- 원본 꽃 사진과 4:3 비율, 메인 '오늘의 꽃 만나기 ↗'는 변경하지 않습니다.

## 검증
- `tests/g3-59-mobile-calendar-status-filters-qa.cjs`에서 Chromium/Linux WebKit의 320·390·440·600·768·1280px 확인: 5개 항목과 숫자, 선택 상태, 가로 레일, 44px 터치 높이, 가로 페이지 넘침 방지.
- 마지막 ‘수령 완료’까지 스크롤하여 선택, ‘전체’ 복귀, 선택 날짜와 건수·합성 예약 및 localStorage 불변, 390px axe WCAG 2.1 AA + 스크린샷.
- 이전 **전체** Chromium·WebKit·axe 회귀 및 신규 QA가 PR **최신 SHA에서 모두 성공한 경우에만** squash 병합, Pages 배포 성공 및 main SHA 일치 확인.
