# G3-70 · 사장용 상품 노출 순서·접기 UX

## 변경 내용
- `owner-studio.html`의 좌측 편집기에서 상품 편집 항목을 **개별 접기·펼치기**, **모두 접기·모두 펼치기** 할 수 있습니다.
- 기존 G3-69의 입력 필드는 **처음에는 펼친 상태**로 유지하여 기존 사용성과 테스트를 보존합니다. 접어도 상품명·가격·예약 가능/품절 상태를 확인할 수 있습니다.
- 각 상품의 **위로/아래로** 버튼으로 '오늘의 꽃'과 '매일의 꽃다발' 내부 노출 순서를 조정합니다. 이동 불가능한 맨 위/아래 버튼은 비활성화됩니다.
- 화면 왼쪽의 노출 순서 변경은 오른쪽 **원본 고객 페이지 iframe 카드 순서**에 즉시 반영됩니다. 상품 이름/가격/품절/사진도 기존처럼 유지됩니다.
- 상품 추가 시 신규 상세 항목은 열리고, 기존 접기 상태는 보존됩니다. 항목 이동·분류 변경에도 접기 상태를 상품 ID별로 유지합니다.
- **편집 내용 초기화**를 누르면 상품 순서와 접기 상태까지 G3-69 초기값으로 돌아갑니다.

## 변경 범위
- `assets/owner-studio.js`: 상품 카테고리 안에서만 순서 이동, 접힌 상품 ID 관리, 정렬 버튼 접근성, 메타정보 실시간 갱신.
- `assets/owner-studio.css`: 편집 제목과 순서/접기 제어의 줄바꿈 및 접힌 상태 표시.
- `owner-studio.html`: 전체 접기/펼치기 명령과 사용법 한 줄.
- `index.html`: 2026-11-12 통합 CI에서 발견한 기존 모바일 달력 `.cal-more` 대비 4.12:1 문제를 해결하기 위해 **해당 한 CSS 색상만** `#647769` → `#465c4b`로 진하게 조정했습니다. 기능·레이아웃·사진·고정 CTA는 변경하지 않았습니다.
- `tests/g3-70-owner-catalog-order-qa.cjs`: Chromium + WebKit 실제 고객 iframe 검증(정렬, 접기, 가격/품절 동기화, 분류 이동, 초기화, 비게시, 320/390/1080/1440px 레이아웃, axe).
- `.github/workflows/g3-17-browser-qa.yml`: **기존 모든 테스트 유지**, G3-70 검사만 추가.

## 변경하지 않은 승인사항
- 실제 고객 사이트의 `index.html`, 기존 상품 사진과 비율, `오늘의 꽃 만나기 ↗` 고정 CTA, 예약 조회·가상 예약·일정 캘린더 로직 불변.
- 편집 데이터와 사진은 열린 탭의 **임시 RAM**에만 존재합니다. 페이지 새로고침 시 삭제되며 서버, 다른 방문자의 화면, 공개 사이트에 반영되지 않습니다.
- 관리자 인증·서버/DB/미디어 저장·외부 업로드·실예약·실입금·실서비스 게시/유료 작업 금지, G2 전체 Gate HOLD 유지.
- Chromium/Linux WebKit 자동화는 실제 iPhone Safari/Instagram WebView 확인을 대체하지 않습니다.

## 합격 조건
1. G3-69와 G3-70 모두 Chromium/WebKit/axe 통과.
2. 통합 GitHub Actions의 기존 회귀 검사도 **정확한 최신 HEAD에서 모두 성공**해야 병합 가능.
3. CI 실패나 사양 충돌 시 PR 상태로 중단, main 및 Pages 보존.
