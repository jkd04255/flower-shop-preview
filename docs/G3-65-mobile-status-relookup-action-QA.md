# G3-65 · 모바일 ‘다른 예약 조회’ 보조 버튼 터치·가독성 개선

## 문제
고객 예약 현황 결과 아래의 ‘다른 예약 조회 ↗’는 이전 검색을 지우고 가상 예약을 다시 확인하는 기존 보조 작업입니다. 모바일에서 13px 글씨와 약 43px의 터치 높이로 표시돼 조작 영역이 작았습니다.

## 수정
- 600px 이하에서 기존 보조 링크형 스타일과 문구를 그대로 유지하며, 최소 48px 높이와 14px 글씨의 분명한 터치 영역으로 조정합니다.
- 배경·색상·하단 밑줄·접근성 포커스·버튼 위치를 유지하며, 폭이 좁거나 글씨가 확대되더라도 줄바꿈을 허용합니다. 별도 카드·색상 강조·버튼·설명 문구를 추가하지 않습니다.
- 601px 이상 데스크톱/태블릿은 기존의 13px 인라인 표시를 그대로 유지합니다.
- 기존 고객 예약 현황 조회→다른 예약 조회→입력 포커스 복귀, 샘플 코드 재조회와 로컬 새로고침, 예약 상태 표시 로직은 변경하지 않습니다.
- 꽃 사진·4:3 비율, **‘오늘의 꽃 만나기 ↗’**, 예약·조회·관리자·캘린더 기능 보존.

- 조회 전 버튼 숨김, 예시 1002 조회 후 표시, 버튼 터치 시 결과 지우기·입력 공란·키보드 포커스 복원, 다른 샘플 1003 재조회, 새로고침, 알 수 없는 샘플 9999 결과 비노출.
