## 실제 브라우저에서 재현된 두 가지 문제

1. **포토 히어로의 예약 체험 링크 대비:** G3-20의 사진 `hero-original.webp` + 그라데이션 + 흰 글씨를 Chromium에서 렌더링하고, 텍스트를 임시로 숨긴 화면과 실제 글자가 표시된 화면의 PNG 픽셀 차이로 **글자가 그려진 위치의 배경**을 비교했습니다. 기존 `오늘의 꽃 만나기` CTA의 하위 10퍼센타일 대비는 **1280px에서 4.11:1**, **390px에서 4.48:1**로 일반 텍스트의 WCAG AA 참고 기준 **4.5:1 미달**로 관찰됐습니다. 다른 제목·본문·브랜드 글씨의 측정 범위는 기준을 충족했습니다. [실패 재현용 발견 검사 run #42453760985](https://github.com/jkd04255/flower-shop-preview/actions/runs/42453760985).
2. **640 CSS px 일간 캘린더의 10px 가로 넘침:** 기존 캘린더의 화면 폭 **640px**에서 본문 안쪽 여백은 `4vw`인데, `.cal-day-title`의 좌우 마진은 데스크톱 설정인 `-5.6vw`가 남아 있어 **약 10px** 페이지 폭을 초과했습니다. 홈, 폼/오류, 관리자, 월간 달력 및 320px 일간 달력은 가로 넘침이 없었습니다.

## 실제 원인만 최소 수정

- 포토 히어로의 기존 어두운 좌→우 그라데이션을 **왼쪽 #252b27a6 → #252b27c7**로 소폭 진하게 했습니다. 사진, 화이트 타이포그래피, 편집형 구조와 하단 크림색 페이드는 유지합니다. G3-21 픽셀 대비 엄격 검사를 다시 실행하여 **링크 포함 테스트 대상 글자의 측정 기준을 통과**했습니다.
- `@media (min-width:441px) and (max-width:800px)`에서 일간 날짜 제목의 마진을 `-4vw`, 안쪽 여백을 `4vw`로 맞춰 실제 640px 가로 넘침이 **0px**으로 확인됐습니다. 320px 기존 G3-19 디자인과 다른 캘린더 기능은 그대로 유지합니다.
- 키보드 초점 스타일은 **이미 정상**이라 변경하지 않았습니다. 실제 Chrome에서 640px·320px의 이전 달→다음 달, 관리자 링크→가상 데이터 초기화, 예약 돌아가기→날짜 입력 요소의 **Tab 이후 focus-visible 및 2px 실선 초점 표시**를 확인했습니다.

## 테스트 및 시행착오 구분

- 최초 테스트에서 예약 오류 요소를 실제 `#rError`가 아닌 존재하지 않는 `#formError`로 선택해 검사 전체가 중단됨. 이를 **테스트만** 보정하고 서비스를 수정하지 않음.
- 사진 그라데이션 수정 후 첫 엄격 검사에서 데스크톱 작은 문구 2곳의 픽셀 샘플 수가 0으로 판정됨. 히어로 'peek' 레이아웃 변화를 안정화하고 사진/텍스트 스크린샷 측정 시점을 보정하여 반복 검증. **서비스 위반이라는 근거가 없던 테스트 수집 문제**로 분리함.
- G3-21 테스트는 발견 모드 `G321_DISCOVERY=1`에서 문제를 출력한 후, 최종적으로 `G321_DISCOVERY=0`인 **엄격 게이트**로 바꾸어 실패를 우회하지 않도록 설정했습니다.
- CI는 여전히 PR마다 **자동 단일 워크플로 1개**. 예전 테스트 삭제 없이 모든 회귀 검사를 유지하고, 이전 실행 취소 정책도 보존.

### 자동화와 실제 줌의 중요한 차이

`1280 → 640 → 320 CSS px`은 **1280 CSS px 레이아웃을 200%/400% 확대할 때의 가용 공간과 동등한 reflow 조건**을 비교한 실브라우저 시나리오입니다. **운영체제/Chromium 네이티브 확대 메뉴를 실제로 200%·400%로 변경한 테스트가 아닙니다.** 따라서 글자 렌더링·운영체제 배율의 모든 부작용을 검증했다고 주장하지 않습니다.

사진 대비 측정은 **실제 이미지·그라데이션이 합성된 픽셀 기반의 자동 샘플**입니다. 글자 주변의 최저 10퍼센타일과 글자 크기별 참고 기준을 비교하며, 사진 전체 영역·모든 명도 변화·개인별 시각 차이에 대한 완전한 WCAG 적합성 판정이 아닙니다. axe-core가 `incomplete`로 분류한 포토·다층 배경 대비 판정은 향후 수동 검사 대상으로 남깁니다.
