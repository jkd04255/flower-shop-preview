## 수정 범위

1. 날짜·정시 슬롯별 확정 건수는 `confirmed`, `ready`, `completed`만 합산.
2. 시연용 정원이 3건일 때 미확정 예약의 관리자 수동 확정 버튼 비활성화 + 설명 표시. 기존 `pending` 요청 자동 삭제/거절 없음.
3. 고객 가상 예약 시연에서 정원이 이미 찬 슬롯은 선택 대상에서 제외하고, 폼 제출 때 동일 규칙으로 재검증.
4. 일간 캘린더에서는 같은 시간 중복과 가상 확정 3/3 마감을 함께 안내.
5. 실입금·은행 연결·실제 고객 데이터·실메일/SMS·실예약·DB/인증·과금은 일절 연결하지 않음.

- 원본 JS 스크립트 3개 구문 파싱: 통과.
- 기존 UI 구성/달력/사진/은행 시연 기능 유지에 관한 정적 검사 9건: 통과.
- 실제 수정 소스에서 함수를 추출해 격리 실행한 합성 데이터 기능 테스트 11건: 통과.

## 변경 통제

원본 G3-09의 `index.html`은 기능 브랜치에 기록하고 PR 심사를 거친다. 공개 GitHub Pages는 기존 **가상 시안**으로만 유지한다. G2 전체 Gate HOLD와 실제 서비스 연동 미승인 상태는 변경하지 않는다. 실제 정원 초과 방지는 서버 DB 락 및 권한 검증, G4 경합 시험이 별도로 필요하다.
