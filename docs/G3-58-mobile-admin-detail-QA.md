# G3-58 · 모바일 관리자 예약 상세 패널의 픽업 정보 및 처리 버튼 가독성

## 기획과 범위
G3-57 모바일 예약 목록 카드 디자인과 연결하여 관리자가 예약 하나를 선택한 후 **픽업 날짜·시간**과 **다음 처리 버튼**을 더 쉽게 읽고 조작하도록 개선합니다. 승인된 크림/그린 분위기와 모든 흐름을 그대로 유지합니다.

- 600px 이하 예약 상세 패널에만 CSS를 적용하고, 여백 및 타이포그래피 위계를 정리합니다.
- 기존 8개 정보행을 삭제하거나 재정렬하지 않고, 픽업 날짜(3번째)·시간(4번째)만 16px/굵은 글자로 부각합니다.
- 상세 정보의 2열 레이아웃은 왼쪽 라벨 80px / 오른쪽 값 나머지 너비로 맞춰 모바일 가로 넘침을 방지합니다.
- 기존 관리자 처리 버튼 2개는 각각 최소 48px, 캘린더 이동 버튼은 최소 44px로 조정합니다.
- 처리 버튼의 활성화/비활성화 조건, 가상 입금확인, 상태 전이, 미발송 안내, 캘린더로 이동, 검색·정렬·필터 로직은 변경하지 않습니다.
- 601px 이상 태블릿·데스크톱 기존 배치는 변경하지 않습니다.
- 기존 꽃 사진과 모바일 4:3 비율, '오늘의 꽃 만나기 ↗', 예약·고객 조회·관리자·캘린더를 보존합니다.

## QA
`tests/g3-58-mobile-admin-detail-qa.cjs`는 Chromium/Linux WebKit 양쪽에서 320·390·600·768·1280px의 모바일 패널, 8개 원본 정보, 날짜·시간 강조, 두 처리 버튼, 터치 높이 및 페이지 가로 넘침을 확인합니다. 예약 선택 시 상세 값 동기화, 상태 필터 초기화, 합성 예약과 localStorage 불변, 390px axe-core WCAG 2.1 AA 검증, 스크린샷도 포함합니다.
